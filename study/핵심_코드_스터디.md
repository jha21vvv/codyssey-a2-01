## 1. 사선 공식(Shoelace Formula) 기반 다각형 면적 계산 (`src/linear_algebra.py`)

### 선정 이유
행렬 변환 후 도형의 넓이가 실제로 $|\det(A)|$배만큼 변했는지 검증하는 기하학 핵심 알고리즘입니다. `np.roll`을 활용한 벡터화 연산은 반복문 없이 배열을 한 칸씩 밀어 인접 원소를 짝짓는 NumPy 실무 패턴의 정석입니다.

```python
# [1차-단어분해]: x(배열), =(대입), pts(2D 좌표 배열), [0](0번째 행 인덱싱 — 모든 점의 x좌표 추출)
# [2차-예시/비유]: 예) 점이 3개일 때 x = [1.0, 0.0, -1.0]처럼 바구니에서 x좌표 이름표만 쏙 뽑아옵니다.
x = pts[0]
# [1차-단어분해]: y(배열), =(대입), pts(2D 좌표 배열), [1](1번째 행 인덱싱 — 모든 점의 y좌표 추출)
# [2차-예시/비유]: y좌표 이름표들도 별도의 바구니에 나란히 담아둡니다.
y = pts[1]
# [1차-단어분해]: np.roll(배열 회전 함수), x(대상 배열), -1(왼쪽으로 1칸 이동; 첫 원소가 맨 뒤로 감)
# [2차-예시/비유]: 운동회 강강술래처럼 옆 사람의 x좌표를 내 앞으로 한 칸씩 당겨 짝을 짓습니다.
x_next = np.roll(x, -1)
# [1차-단어분해]: np.roll(배열 회전 함수), y(대상 배열), -1(왼쪽으로 1칸 이동)
# [2차-예시/비유]: 마찬가지로 내 다음 순번 친구의 y좌표를 짝꿍으로 데려옵니다.
y_next = np.roll(y, -1)
# [1차-단어분해]: return(반환), float(파이썬 실수형 변환), 0.5 *(절반 곱), np.abs(절댓값), np.sum(원소 총합), (x * y_next - x_next * y)(신발끈 교차 곱셈 차)
# [2차-예시/비유]: 운동화 끈을 X자로 묶듯 앞뒤 좌표를 엇갈려 곱하고 뺀 뒤 전부 더해 반으로 나누면, 어떤 다각형이든 정확한 넓이가 나옵니다.
return float(0.5 * np.abs(np.sum(x * y_next - x_next * y)))
```

## 2. Power Iteration 최대 고유값·고유벡터 탐색 (`src/linear_algebra.py`)

### 선정 이유
Google PageRank, PCA, 스펙트럴 클러스터링의 근간이 되는 반복법입니다. 행렬을 계속 곱하면서 크기가 폭발하지 않도록 단위 벡터로 정규화(`b / ||b||`)하는 패턴은 수치해석에서 필수적입니다.

```python
# [1차-단어분해]: b_next(다음 벡터), =(대입), mat(N×N 정방 행렬), @(행렬-벡터 곱셈 연산자), b(현재 단위 벡터)
# [2차-예시/비유]: 현재 화살표 b에 바람(행렬 mat)을 한 번 불어 화살표의 방향과 길이를 바꿉니다. 예) 2x2 행렬 @ (2,) 벡터 -> (2,) 벡터
b_next = mat @ b
# [1차-단어분해]: norm_next(스칼라 노름), =(대입), np.linalg.norm(유클리드 L2 길이 계산 함수), b_next(대상 벡터)
# [2차-예시/비유]: 바람을 맞고 길어진 화살표의 총 길이를 자로 잽니다. 예) [3, 4] -> 길이 5.0
norm_next = np.linalg.norm(b_next)
# [1차-단어분해]: b_next(정규화된 벡터), =(대입), b_next / norm_next(벡터 각 성분을 스칼라 길이로 나눔)
# [2차-예시/비유]: 화살표가 너무 길어져 숫자가 폭발하지 않도록 길이를 딱 1짜리 표준 화살표로 줄입니다.
b_next = b_next / norm_next
# [1차-단어분해]: new_eigenvalue(스칼라), =(대입), float(실수 변환), b_next.T(전치 벡터), @(내적), mat @ b_next(변환된 벡터)
# [2차-예시/비유]: 표준 화살표가 행렬을 한 번 통과했을 때 원래 방향으로 몇 배 늘어났는지(고유값) 레일리 몫으로 측정합니다.
new_eigenvalue = float(b_next.T @ mat @ b_next)
```

## 3. SVD 특이값 분해 기반 이미지 Rank-k 복원 (`src/linear_algebra.py`)

### 선정 이유
추천 시스템, 노이즈 제거, 차원 축소(PCA)에서 가장 널리 쓰이는 저랭크 근사(Low-rank Approximation) 코드입니다. `u[:, :k_eff] * s[:k_eff]` 브로드캐스팅은 대각행렬 `np.diag(s)`를 만들지 않고도 메모리를 아끼는 실무 최적화 기법입니다.

```python
# [1차-단어분해]: u, s, vt(좌특이벡터, 특이값 1D배열, 우특이벡터 전치), =(언패킹 대입), np.linalg.svd(특이값 분해), img(2D 배열), full_matrices=False(축소형 SVD)
# [2차-예시/비유]: 거대한 그림(64×64)을 '가로 붓터치(u)', '붓터치 중요도(s)', '세로 붓터치(vt)' 3개의 서랍으로 분해합니다.
u, s, vt = np.linalg.svd(img, full_matrices=False)
# [1차-단어분해]: k_eff(유효 랭크), =(대입), min(최솟값 함수), k(요청 개수), len(s)(전체 특이값 개수)
# [2차-예시/비유]: 64색 크레파스 중에서 100개를 뽑아달라고 해도 최대 64개까지만 뽑도록 안전하게 제한합니다.
k_eff = min(k, len(s))
# [1차-단어분해]: reconstructed(복원 이미지), =(대입), u[:, :k_eff](상위 k열), *(브로드캐스팅 곱), s[:k_eff](상위 k개 특이값), @(행렬 곱), vt[:k_eff, :](상위 k행)
# [2차-예시/비유]: 가장 중요한 상위 k개의 붓터치만 골라서 다시 캔버스 위에 겹쳐 그림을 복원합니다.
reconstructed = (u[:, :k_eff] * s[:k_eff]) @ vt[:k_eff, :]
```

## 4. 중심차분법(Central Difference) 다변수 Gradient (`src/calculus.py`)

### 선정 이유
딥러닝에서 직접 유도한 역전파(Backprop)가 맞는지 검증하는 **Gradient Checking**의 핵심 로직입니다. 각 차원 `i`만 `±h` 흔들고 원상 복구(`p[i] = orig`)하는 패턴은 수치 미분의 기본기입니다.

```python
# [1차-단어분해]: orig(원래 좌표값 백업), =(대입), p[i](i번째 차원 원소 추출)
# [2차-예시/비유]: x축 방향으로 살짝 발을 내디딜 것이므로, 원래 서 있던 위치를 분필로 표시해둡니다.
orig = p[i]
# [1차-단어분해]: p[i](원소 수정), =(대입), orig + h(양의 방향으로 미소 이동)
# [2차-예시/비유]: 오른쪽으로 아주 작은 보폭(h=0.00001)만큼 한 발 내딛습니다.
p[i] = orig + h
# [1차-단어분해]: f_plus(스칼라 함숫값), =(대입), float(실수 변환), func(p)(이동한 위치의 함수 평가)
# [2차-예시/비유]: 오른쪽 발을 디딘 곳의 산 높이(함수값)를 측정합니다.
f_plus = float(func(p))
# [1차-단어분해]: p[i](원소 수정), =(대입), orig - h(음의 방향으로 미소 이동)
# [2차-예시/비유]: 이번에는 기준점에서 왼쪽으로 똑같은 보폭(h)만큼 발을 내딛습니다.
p[i] = orig - h
# [1차-단어분해]: f_minus(스칼라 함숫값), =(대입), float(실수 변환), func(p)(이동한 위치의 함수 평가)
# [2차-예시/비유]: 왼쪽 발을 디딘 곳의 산 높이를 측정합니다.
f_minus = float(func(p))
# [1차-단어분해]: p[i](원상 복구), =(대입), orig(백업해둔 원래 값)
# [2차-예시/비유]: 다음 차원(y축)을 재기 전에 반드시 원래 제자리로 돌아옵니다.
p[i] = orig
# [1차-단어분해]: grad[i](i번째 편미분 값), =(대입), (f_plus - f_minus)(높이 차), /(나눗셈), (2.0 * h)(양쪽 보폭 합 2h)
# [2차-예시/비유]: (오른쪽 높이 - 왼쪽 높이) ÷ 양쪽 거리(2h)로 현재 지점의 정확한 오르막 경사를 계산합니다.
grad[i] = (f_plus - f_minus) / (2.0 * h)
```

## 5. Momentum 옵티마이저 스텝 업데이트 (`src/optimizer.py`)

### 선정 이유
SGD에 관성(`beta=0.9`)을 더한 가장 대표적인 1차 최적화 기법입니다. Adam 등 현대 옵티마이저의 1차 모멘트(`m_t`)도 바로 이 2줄의 코드에서 출발합니다.

```python
# [1차-단어분해]: self.velocity(누적 속도 벡터), =(대입), self.beta(관성 계수 0.9), *(곱셈), self.velocity(이전 속도), +(덧셈), g(현재 기울기 벡터)
# [2차-예시/비유]: 굴러가던 볼링공의 기존 속도 90%를 유지한 채, 현재 경사가 밀어주는 힘(g)을 새로 보태줍니다.
self.velocity = self.beta * self.velocity + g
# [1차-단어분해]: return(반환), p(현재 파라미터 벡터), -(뺄셈), self.lr(학습률 스칼라), *(곱셈), self.velocity(업데이트된 속도 벡터)
# [2차-예시/비유]: 계산된 총 속도 방향으로 학습률(보폭)만큼 굴러 내려간 새로운 위치를 반환합니다.
return p - self.lr * self.velocity
```

## 6. 수치 안정적 Softmax 확률 변환 (`notebooks/probability_loss.ipynb`)

### 선정 이유
분류 모델의 마지막 층에서 로짓(Logit)을 확률 분포로 바꿀 때, `exp(1000)`이 `inf(오버플로우)`로 터지는 것을 막기 위해 최댓값을 빼주는 실무 필수 테크닉입니다.

```python
# [1차-단어분해]: shifted(이동된 배열), =(대입), z(입력 로짓 배열), -(브로드캐스팅 뺄셈), np.max(z)(배열 내 최댓값 스칼라)
# [2차-예시/비유]: 가장 큰 점수가 0점이 되도록 모든 점수에서 최댓값을 똑같이 빼주어 지수 함수 폭발(Overflow)을 원천 차단합니다. 예) [1000, 1001] -> [-1, 0]
shifted = z - np.max(z)
# [1차-단어분해]: exp_z(양수 변환 배열), =(대입), np.exp(shifted)(자연상수 e의 거듭제곱 계산)
# [2차-예시/비유]: 음수나 0이 된 안전한 점수들을 모두 0보다 큰 양수 힘으로 바꿉니다. 예) [e^-1, e^0] = [0.368, 1.0]
exp_z = np.exp(shifted)
# [1차-단어분해]: return(반환), exp_z(분자 배열), /(나눗셈), np.sum(exp_z)(전체 합 스칼라)
# [2차-예시/비유]: 전체 합으로 나누어 다 합치면 정확히 1.0(100%)이 되는 확률표로 만들어 반환합니다.
return exp_z / np.sum(exp_z)
```
