## 항목 3 (PASS) — 심층 원리 · 구현 근거 구술 질문 (5문항)

### Q3-1. 행렬식(`det`)이 면적 변화율과 같다는 것을 왜 검증해야 하며, 본인의 코드에서 이를 어떻게 확인했는지 설명해 주세요.
- **왜 검증해야 하는가?**:
  - 선형 변환에서 `|det(A)|`는 단순한 계산 공식(`ad - bc`)이 아니라 **행렬 곱셈이 데이터 공간의 넓이(3D에서는 부피)를 몇 배로 늘리거나 찌그러뜨리는지 나타내는 기하학적 척도(= 선형 변환의 자코비안 행렬식)**입니다.
  - 특히 `det(A) = 0`이면 2D 공간이 선이나 점으로 뭉개져 정보가 비가역적으로 소실(역행렬 불가)되므로, AI에서 가중치 행렬이 공간을 어떻게 변형하는지 이해하는 핵심 지표입니다.
- **코드에서의 검증 방식 ([`src/linear_algebra.py`](../src/linear_algebra.py))**:
  1. `generate_unit_circle(100)`으로 `(2, 100)` 단위 원 점 집합을 생성하고 `transformed = mat @ circle`로 일괄 변환합니다.
  2. `compute_polygon_area()`가 `np.roll(x, -1)`을 이용한 **사선 공식(Shoelace Formula)** $\frac{1}{2}|\sum(x_i y_{i+1} - x_{i+1} y_i)|$로 변환 전 넓이(`area_before`)와 변환 후 넓이(`area_after`)를 직접 측정합니다.
  3. `verify_determinant_area()`가 실제 면적 비율 `area_after / area_before`와 `abs(np.linalg.det(mat))`의 상대 오차를 계산하며, 회전·스케일링·전단 3종 모두 오차 **`0.000000`** (`< 1%`)으로 완벽 일치를 확인했습니다.

### Q3-2. Power Iteration에서 대칭행렬을 테스트 행렬로 사용한 이유는 무엇이며, 수렴 조건(`tol`, `max_iter`)을 어떻게 설정했는지 설명해 주세요.
- **대칭행렬($A = A^T$)을 테스트 행렬로 사용한 이유**:
  *(검증 행렬: `[[4.0, 1.0, 0.5], [1.0, 3.0, 0.2], [0.5, 0.2, 2.0]]`)*
  1. **모든 고유값이 실수(Real) 보장**: 스펙트럼 정리(Spectral Theorem)에 의해 실수 대칭행렬은 복소수(허수) 고유값이 절대 나타나지 않아, 실수 벡터 공간의 Power Iteration이 진동 없이 안정적으로 수렴합니다.
  2. **직교 고유벡터 & 대각화 가능**: 서로 다른 고유값에 대응하는 고유벡터가 90° 직교하므로, 임의 초기 벡터를 고유벡터 기저로 분해했을 때 지배 고유값($\lambda_1^k$) 성분이 깔끔하게 분리됩니다.
  3. **Rayleigh Quotient의 빠른 수렴**: 대칭행렬에서 $b^T A b$는 오차가 벡터 오차의 제곱(2차 수렴)으로 줄어들어 `np.linalg.eig` 대비 **`5.64e-16`**의 극고정밀도를 달성합니다. *(실제 PCA의 공분산 행렬 $X^T X$나 SVD의 $A A^T$도 모두 대칭행렬!)*
- **수렴 조건 설정 (`num_iters=1000`, `tol=1e-9`)**:
  - `num_iters = 1000`: 고유값 간격이 좁거나 수렴이 느린 경우에도 무한 루프에 빠지지 않도록 안전한 반복 상한을 두었습니다.
  - `tol = 1e-9`: 직전 스텝 대비 **고유값 변화량(`abs(new_eigenvalue - eigenvalue) < tol`)과 고유벡터 변화량(`np.linalg.norm(b_next - b) < tol`)을 모두 충족할 때** 조기 종료하도록 이중 수렴 조건을 걸어 고유값과 고유벡터 양쪽의 정확도를 보장했습니다.

### Q3-3. 2층 신경망의 역전파에서 연쇄 법칙이 왜 필요한지, 그리고 `∂L/∂W1`까지의 유도 과정을 자신의 손계산을 보며 설명해 주세요.
- **연쇄 법칙이 왜 필요한가?**:
  - 입력층 가중치 `W1`은 손실 `L`에 직접 들어 있지 않고, **`W1 → z1 → a1 → z2 → y_pred → L`**처럼 여러 합성 함수를 거쳐 연결되어 있습니다.
  - 따라서 `W1`이 `L`에 미치는 기울기 `∂L/∂W1`을 구하려면, 각 단계의 국소 미분(Local Gradient)을 **출력층에서 입력층 방향으로 차례대로 곱해 전달하는 연쇄 법칙(Chain Rule)**이 필수적입니다.
- **고정 예제(`x=[1,0]`, `W1=[[0.1,0.2],[0.3,0.4]]`, `W2=[0.5,0.6]`, `y=1`) 손계산 유도 흐름**:
  - *(순전파 체크포인트)* `z1=[0.1, 0.2]` → `a1=[0.5250, 0.5498]` → `z2=0.5924` → `y_pred=0.6439` → `L=0.4402`
  1. $\dfrac{\partial L}{\partial \hat{y}} = -\dfrac{1}{0.6439} = \mathbf{-1.5530}$ `shape: ()`
  2. $\dfrac{\partial L}{\partial z_2} = \dfrac{\partial L}{\partial \hat{y}} \cdot \sigma'(z_2) = \hat{y} - y = 0.6439 - 1 = \mathbf{-0.3561}$ `shape: ()` *(BCE·Sigmoid 약분!)*
  3. $\dfrac{\partial L}{\partial W_2} = \dfrac{\partial L}{\partial z_2} \cdot a_1 = (-0.3561)[0.5250, 0.5498] = \mathbf{[-0.1869, -0.1958]}$ `shape: (2,)`
  4. $\dfrac{\partial L}{\partial a_1} = \dfrac{\partial L}{\partial z_2} \cdot W_2 = (-0.3561)[0.5, 0.6] = \mathbf{[-0.1780, -0.2137]}$ `shape: (2,)`
  5. $\dfrac{\partial L}{\partial z_1} = \dfrac{\partial L}{\partial a_1} \odot a_1(1 - a_1) = [-0.1780, -0.2137] \odot [0.2494, 0.2475] = \mathbf{[-0.0444, -0.0529]}$ `shape: (2,)`
  6. $\dfrac{\partial L}{\partial W_1} = x^T \otimes \dfrac{\partial L}{\partial z_1} = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \begin{bmatrix} -0.0444 & -0.0529 \end{bmatrix} = \begin{bmatrix} \mathbf{-0.0444} & \mathbf{-0.0529} \\ \mathbf{0.0000} & \mathbf{0.0000} \end{bmatrix}$ `shape: (2, 2)`
  - 이 손계산 결과는 NumPy 코드 계산과 소수점 4자리 이상(`atol=1e-4`) 완벽히 일치합니다.

### Q3-4. MSE 최소화가 정규분포 가정 하에서 MLE와 동일한 이유를 수식 유도 과정을 보여주며 설명해 주세요.
1. **확률 가정 (정규분포 노이즈)**: 회귀 타깃 $y_i$가 모델 예측값 $\hat{y}_i = f_\theta(x_i)$를 평균으로 하고 분산이 $\sigma^2$인 정규분포를 따른다고 가정합니다.
   $$p(y_i \mid x_i; \theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - \hat{y}_i)^2}{2\sigma^2}\right)$$
2. **우도 함수(Likelihood) 구성**: $N$개의 독립(i.i.d.) 데이터가 관측될 전체 확률을 모두 곱합니다.
   $$\mathcal{L}(\theta) = \prod_{i=1}^{N} p(y_i \mid x_i; \theta)$$
3. **음의 로그 우도(NLL) 최소화 전환**: 우도 최대화($\max \mathcal{L}$)는 $-\log \mathcal{L}$ 최소화($\min$)와 동치이며, $\log$가 곱셈을 덧셈으로 바꾸고 `exp`를 상쇄합니다.
   $$-\log \mathcal{L}(\theta) = \sum_{i=1}^{N} \left[ \frac{1}{2}\log(2\pi\sigma^2) + \frac{(y_i - \hat{y}_i)^2}{2\sigma^2} \right]$$
4. **결론**: 파라미터 $\theta$와 무관한 상수항 $\frac{1}{2}\log(2\pi\sigma^2)$과 양의 상수 $\frac{1}{2\sigma^2}$를 제거하고 $N$으로 나누면 정확히 **MSE 최소화**가 됩니다.
   $$\theta_{\text{MLE}} = \arg\min_{\theta} \frac{1}{N}\sum_{i=1}^{N} (y_i - \hat{y}_i)^2 = \arg\min_{\theta} \text{MSE}(\theta)$$

### Q3-5. Momentum이 Vanilla GD보다 빠르게 수렴하는 원리를 설명하고, 타원형 함수($x^2 + 10y^2$)에서 그 차이가 더 두드러지는 이유를 실험 결과와 함께 설명해 주세요.
- **빠르게 수렴하는 원리**:
  - `VanillaGD` ($\theta_{t+1} = \theta_t - \text{lr} \cdot g_t$)는 과거 이동 기록 없이 매 스텝 현재 기울기만 봅니다.
  - 반면 `Momentum` ($v_{t+1} = \beta v_t + g_t$, $\theta_{t+1} = \theta_t - \text{lr} \cdot v_{t+1}$, $\beta=0.9$)은 이전 속도의 90%를 관성으로 누적합니다.
  - 따라서 **부호가 계속 같은 방향(전진 방향)은 속도가 쌓여 가속**되고, **부호가 매번 바뀌는 방향(진동 방향)은 `+`와 `-`가 더해져 서로 상쇄**됩니다.
- **타원형 함수 $f(x, y) = x^2 + 10y^2$에서 차이가 두드러지는 이유 & 실험 결과**:
  - 기울기가 $\nabla f = [2x, 20y]$로 **y축 곡률이 x축보다 10배 가파릅니다.**
  - 동일 `lr=0.04`·출발점 `(8.0, 2.0)` 실험에서 5회차만에 **`VanillaGD`는 `x = 5.273` (오차 `27.80`)에서 점점 감속**하는 반면, **`Momentum`은 x방향 보폭이 `-0.64 → -1.17 → -1.54 → -1.76 → -1.82`로 가속되며 `x = 1.073` (오차 `7.10`)으로 오차를 4배 빠르게 줄입니다.**
  - 반대로 `VanillaGD`의 속도를 높이려고 `lr=0.085`로 키우면 y축이 `+2.0 → -1.4 → +0.98 → -0.69`로 심하게 지그재그 진동하는 반면, `Momentum`은 [`outputs/opt_comparison_ellipse.png`](../outputs/opt_comparison_ellipse.png)처럼 진동을 억제하며 원점 반경 **`0.0389`**까지 매끄럽게 수렴합니다.

### Q4-4. 2층 신경망에서 연쇄 법칙이 어떻게 적용되는지 수식으로 설명해주세요.
> 출력층 손실 $L$에서 각 가중치 $W_2, W_1$까지의 미분을 중간 변수($\hat{y}, z_2, a_1, z_1$)의 국소 미분 곱으로 분해하여 뒤에서 앞으로 전파합니다.
> $$\frac{\partial L}{\partial W_2} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z_2} \cdot \frac{\partial z_2}{\partial W_2} = (\hat{y} - y)\, a_1$$
> $$\frac{\partial L}{\partial W_1} = x^T \otimes \left( \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial a_1} \odot \frac{\partial a_1}{\partial z_1} \right) = x^T \otimes \big((\hat{y} - y)\, W_2 \odot a_1(1 - a_1)\big)$$

### Q4-5. Momentum이 Vanilla GD보다 빠르게 수렴하는 이유는 무엇인가요?
> 과거 기울기(속도)를 관성 계수 $\beta$(예: `0.9`)만큼 누적($v_{t+1} = \beta v_t + g_t$)하기 때문입니다. 이로 인해 **방향이 일정한 축에서는 속도가 누적되어 가속**되고, **방향이 번갈아 바뀌는 진동 축(예: 타원형 계곡의 가파른 축)에서는 `+`/`-` 기울기가 서로 상쇄되어 지그재그 낭비가 크게 줄어들기 때문**입니다.
