### **1. 미션 소개**

선형대수, 미적분, 확률통계는 AI 모델이 데이터를 처리하고 학습하는 과정의 수학적 기반이다. 신경망의 각 층에서 일어나는 연산은 행렬 곱셈이며, 가중치를 업데이트하는 과정은 경사하강법이라는 최적화 알고리즘을 따른다. 이 미션에서는 수학적 계산과 구현은 NumPy로, 시각화는 Matplotlib/Seaborn을 사용하여 행렬 변환의 기하학적 의미를 시각화하고, 고유값 분해를 직접 구현하며, 연쇄 법칙 기반의 역전파를 수식으로 유도한다. 또한 경사하강법의 수렴 과정을 등고선 위에서 시각화하고, 손실 함수가 확률 분포와 어떻게 연결되는지 탐구한다. 이 경험은 이후 딥러닝 미션에서 AutoGrad 엔진을 구현할 때 수학적 기반이 되며, 모델의 동작 원리를 해석하고 문제를 진단하는 능력을 갖추게 한다.

### **3. 과제 목표**

이 과제를 마친 후, 학습자는 아래를 스스로 설명할 수 있어야 한다.

* 행렬 곱셈이 공간을 어떻게 변형시키는지, 행렬식이 면적 변화율과 어떻게 연결되는지 설명할 수 있다
* 고유값과 고유벡터가 선형 변환에서 어떤 의미를 가지는지, SVD가 데이터 압축에 어떻게 활용되는지 이해한다
* 연쇄 법칙을 사용하여 2층 신경망의 역전파 수식을 유도하고, 각 가중치에 대한 기울기를 손계산할 수 있다
* MSE와 Cross-Entropy 손실 함수의 확률적 의미를 구분하고, MLE와의 연결을 수식으로 설명할 수 있다
* Learning Rate와 Momentum이 경사하강법 수렴에 미치는 영향을 실험 결과와 함께 설명할 수 있다

### **4. 기능 요구 사항**

다음 요구사항을 모두 만족해야 한다.

1. 선형대수: 행렬 변환과 분해
   * 단위 원에 회전 행렬 R(θ)를 적용하고 변환 전후를 하나의 Figure에 겹쳐 출력한다
   * 단위 원에 스케일링 행렬 S(2, 0.5)를 적용하고 타원 형태의 결과를 출력한다
   * 단위 원에 전단 행렬 Sh(k)를 적용하고 기울어진 형태의 결과를 출력한다
   * 행렬식 det(A)를 계산하고, 변환 후 도형의 면적 비율과 비교하여 오차가 1% 이내임을 확인한다
   * Power Iteration 알고리즘을 구현하여 최대 고유값을 계산한다
   * 직접 계산한 고유값과 np.linalg.eig 결과를 비교하여 오차가 5% 이내임을 확인한다
   * SVD를 활용하여 이미지를 압축하고, k=10, 50, 100일 때 복원 결과를 하나의 Figure에 비교 출력한다
2. 미적분: Gradient 시각화
   * f(x)=x²에서 x=3일 때 수치 미분을 계산하고, 해석적 미분 결과(6)와 비교하여 오차가 1e-4 이내임을 확인한다
   * 2변수 함수 f(x,y)=x²+y²의 등고선 그래프를 그린다
   * 등고선 위 여러 점에서 Gradient 방향을 화살표로 표시한다
   * Gradient 화살표가 등고선에 수직임을 시각적으로 확인한다
3. 역전파: 연쇄 법칙 수식 유도
   * 2층 신경망(입력 2개 → 은닉 2개 → 출력 1개)의 순전파 수식을 노트북에 작성한다
   * 출력층에서 입력층 방향으로 연쇄 법칙을 적용하여 역전파 수식을 단계별로 유도한다
   * 구체적인 숫자 예제로 순전파를 손계산한다
     * 입력: x = [1, 0]
     * 가중치 1: W1 = [[0.1, 0.2], [0.3, 0.4]]
     * 편향 1: b1 = [0, 0]
     * 가중치 2: W2 = [0.5, 0.6]
     * 편향 2: b2 = 0
     * 활성화 함수: Sigmoid
     * 손실 함수: Binary Cross-Entropy (BCE) L = -(y·log(ŷ) + (1-y)·log(1-ŷ))
     * 정답: y_true = (이진 분류 표준값 1로 설정)
   * 순전파 중간값 : z1, a1, z2, y_pred 각각을 기록한다
   * 역전파 필수 유도 : ∂L/∂y_pred, ∂L/∂z2, ∂L/∂W2, ∂L/∂a1, ∂L/∂z1, ∂L/∂W1 모두 유도한다
   * 각 단계에서 텐서의 shape을 반드시 표기한다 (예: W1: (2,2), x: (2,), z1: (2,) 등)
   * NumPy 코드로 동일한 계산을 수행하고, 손계산 결과와 소수점 4자리까지 일치함을 확인한다
4. 최적화: 경사하강법 시각화
   * Vanilla GD를 구현하고 f(x,y)=x²+y²에 적용한다
   * lr=0.1, 100회 반복 후 (x,y)가 원점 근처(반경 0.1 이내)에 도달함을 확인한다
   * 수렴 경로를 등고선 위에 점선으로 출력한다
   * lr=0.5 이상에서 최적화 경로가 발산함을 그래프로 확인한다
   * Momentum(beta=0.9)을 구현하고 Vanilla GD와 수렴 경로를 비교한다
   * 두 옵티마이저의 수렴 경로를 하나의 Figure에 겹쳐 출력한다
   * 타원형 함수 f(x,y)=x²+10y²에서도 Vanilla GD와 Momentum의 수렴 경로를 비교하여 Momentum의 이점을 확인한다
5. 확률/통계: 손실 함수의 수학적 기반
   * 정규분포 N(0,1)과 N(2,0.5)의 PDF 곡선을 하나의 Figure에 비교 출력한다
   * 베르누이 분포 B(0.3)과 B(0.7)의 PMF 막대그래프를 하나의 Figure에 비교 출력한다
   * 소프트맥스 함수를 구현하고, 출력 벡터의 합이 1.0과의 차이가 1e-6 이내임을 확인한다
   * "MSE 최소화 = 정규분포 가정 하의 MLE"임을 수식으로 유도하여 노트북에 작성한다
   * "Cross-Entropy 최소화 = 베르누이/카테고리 분포 가정 하의 MLE"임을 수식으로 유도하여 노트북에 작성한다

## 3. 3개월 차 주니어 눈높이 핵심 원리 (일상 비유)

1. **행렬 변환과 행렬식 (`linear_algebra.py`) — "고무판 늘리기와 넓이 배율"**
   - 단위 원은 반지름 1짜리 고무판 위에 그린 동그라미입니다. 회전 행렬은 고무판을 돌리기만 하니 넓이가 그대로(1배)이고, 스케일링 행렬 `S(2, 0.5)`는 가로로 2배 늘리고 세로로 절반 줄이니 결국 넓이는 $2 \times 0.5 = 1$배입니다. **행렬식 `det(A)`는 이 고무판이 몇 배 넓어졌는지 알려주는 마법의 숫자**입니다.
2. **Power Iteration & SVD — "가장 센 바람 방향 찾기 & 대표 성분만 챙기기"**
   - **Power Iteration**은 화살표에 계속 같은 행렬을 곱하면서 결국 **가장 크게 늘어나는 주력 방향(최대 고유벡터)**과 그 배율(최대 고유값)을 찾아내는 방법입니다.
   - **SVD 이미지 압축**은 사진이라는 거대한 숫자 표에서 **눈에 잘 띄는 핵심 붓터치(큰 특이값 $k$개)만 골라 저장**하고, 자잘한 디테일은 버려서 용량을 줄이는 기술입니다.
3. **수치 미분과 Gradient (`calculus.py`) — "안대 쓰고 양옆 발 내디뎌 경사 재기"**
   - 함수의 정확한 미분 공식을 몰라도 현재 위치에서 아주 조금 앞(`x+h`)과 뒤(`x-h`)의 높이 차이를 재서 기울기를 구하는 것이 **중심차분법**입니다. 등고선 지도에서 **가장 가파른 오르막 방향(Gradient)**은 항상 등고선과 **수직(90도)**을 이룹니다.
4. **역전파 연쇄 법칙 (`backprop_derivation.ipynb`) — "릴레이 책임 분배"**
   - 최종 시험 점수(Loss)가 틀렸을 때, 출력층부터 거꾸로 타고 내려오며 *"네가 몇 % 기여했는지"*를 곱셈으로 전달(Chain Rule)하여 각 가중치($W_2, W_1$)의 수정량을 구합니다.
5. **VanillaGD vs Momentum (`optimizer.py`) — "브레이크 없는 썰매 vs 묵직한 볼링공"**
   - 좁고 가파른 타원형 계곡($x^2+10y^2$)에서 기본 경사하강법(VanillaGD)은 양쪽 벽에 부딪히며 지그재그로 헤맵니다. 반면 **모멘텀(Momentum)**은 이전 방향의 **관성(속도)**을 기억하는 무거운 볼링공처럼 위아래 진동을 서로 상쇄하고 골짜기 바닥으로 매끄럽게 굴러갑니다.

### 4.2 선형대수 핵심 연산 파이프라인
![선형대수 파이프라인](diagrams/02_linear_algebra_pipeline.png)

- **맨 위 줄(파랑→초록)**: 단위 원 점들을 행렬 $R, S, Sh$에 통과시킨 뒤, 다각형 면적 비율이 행렬식 $|\det(A)|$와 1% 이내로 일치하는지 확인하는 흐름입니다.
- **가운데 줄(노랑)**: 아무 초기 벡터 $b_0$에 행렬 $A$를 반복해서 곱하고 길이를 1로 줄이는 과정을 거쳐 최대 고유값을 찾고, `np.linalg.eig`와 비교합니다.
- **맨 아래 줄(보라)**: 64×64 이미지를 `U, Σ, V^T` 세 조각으로 쪼갠 뒤, 상위 $k=10, 50, 100$개만 다시 합쳐 복원 품질(MSE)을 비교합니다.

### 4.3 2층 신경망 순전파 & 역전파 연쇄 법칙 흐름도
![역전파 연쇄 법칙](diagrams/03_backprop_chain_rule.png)

- **위쪽 파란 화살표(순전파)**: 입력 `[1, 0]`이 `z1 → a1 → z2 → y_pred`를 거쳐 최종 오차 `BCE Loss (0.4402)`까지 계산되는 정방향 길입니다.
- **보라색 화살표**: Loss에서 시작해 거꾸로 되돌아가는 출발점입니다.
- **아래쪽 빨간 화살표(역전파)**: $\partial L/\partial \hat{y}$부터 차례로 미분값을 곱하며 $\partial L/\partial W_2$와 $\partial L/\partial W_1$까지 도달합니다. 각 박스마다 `(2,)`, `(2, 2)` 같은 텐서 크기(shape)가 적혀 있어 행렬 곱셈 규격을 한눈에 확인할 수 있습니다.

### 4.4 최적화 & 확률-손실함수 연결 구조
![최적화 및 MLE 흐름](diagrams/04_optimizer_mle_flow.png)

- **왼쪽 박스 2개**: 회귀 문제의 정규분포 가정은 **MSE**로, 분류 문제의 베르누이/카테고리 분포 가정은 **Cross-Entropy**로 연결됨을 보여줍니다.
